# T10 — Primeiro encontro cooperativo

**Base:** `2741c6a` (T09 aprovado)

**Edição:** build de validação Vite `MODE=e2e`, servido de `dist-e2e`
**Escopo:** entrada virtual pela fronteira do `InputHub`; simulação, relógio, combate, pausa e resgate continuam reais.

## Causalidade

- **RED:** `npm run test:e2e -- tests/e2e/coop-slice.spec.ts` no servidor anterior à mudança falhou em `snapshot()` com `TestBridge indisponível neste build`. O treino e a sessão abriram; faltava a ponte de observação/entrada que permite provar o comportamento.
- **GREEN:** o mesmo teste passou no build e2e. P1 moveu sem deslocar P2; o disparo real reduziu HP do alvo; a pausa congelou o tick; a ação visível de treino colocou P1 em queda e P2 completou o resgate com 40 HP.

## Artefato

O vídeo automatizado do cenário cooperativo, gravado pelo Chromium no build e2e, está em [`T10-controls-feedback-revive.webm`](./T10-controls-feedback-revive.webm). O input desse vídeo é virtual e serve à prova automatizada; não é playtest humano nem valida ghosting, controles físicos, sensação ou diversão.
